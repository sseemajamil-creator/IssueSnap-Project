Abstract

IssueSnap is an AI-powered smart civic issue detection, reporting and management system developed as a final-year engineering research project. The platform integrates computer vision, natural language processing, and geographic information systems to automate the classification of civic infrastructure problems from citizen-submitted photographs. Using transfer learning on MobileNetV2 and EfficientNetB0 architectures, the system supports 7 complaint categories. NLP-based duplicate detection using TF-IDF cosine similarity reduces redundant reports. A transparent rule-based priority prediction system assists administrators in triaging complaints. The system is built on Django with a MySQL backend and deployed with a professional, mobile-responsive UI.

Introduction

Urban public infrastructure degradation poses significant challenges for city administrators and citizens. Potholes, broken streetlights, water leakage, and garbage overflow directly impact quality of life and public safety. Traditional reporting methods — hotlines, in-person visits — are inefficient and difficult to track. IssueSnap addresses this by providing a digital platform where citizens photograph issues, AI classifies them, and administrators manage resolution through a data-driven workflow.

Problem Statement

How can a deep learning-based image classification system, combined with NLP analysis and geographic tracking, improve the efficiency and accuracy of civic issue reporting and management compared to manual, text-based complaint systems?

Research Objectives

  • Design and train a CNN-based classifier for 7 civic issue categories using publicly available datasets.
  • Implement NLP-based duplicate complaint detection using TF-IDF and cosine similarity.
  • Develop a transparent rule-based priority prediction system.
  • Build a full-stack civic issue management platform with real AI integration.
  • Evaluate model performance using accuracy, precision, recall, F1-score, and inference time.

Proposed Methodology

The system follows a multi-modal AI pipeline:

  1. Image preprocessing using OpenCV (resize, normalize, augment)
  2. Transfer learning on MobileNetV2 / EfficientNetB0 (ImageNet weights)
  3. Fine-tuning final layers on civic issue datasets
  4. NLP analysis using TF-IDF vectorization and cosine similarity
  5. Geographic analysis using Haversine formula for proximity detection
  6. Priority scoring using transparent rule-based system

Known Limitations

  • Model performance depends on dataset quality and size. Small datasets may limit accuracy.
  • The rule-based priority system does not use learned weights — suitable for transparency but may miss complex patterns.
  • Geographic duplicate detection requires GPS coordinates from citizens, which may not always be available.
  • The system does not currently support real-time video or streaming.

Future Work

  • Collect and annotate a larger Pakistan-specific civic issue dataset.
  • Implement YOLO-based object detection for precise localization within images.
  • Train an ML-based priority classifier on historical resolved complaint data.
  • Add real-time push notifications using WebSockets.
  • Integrate with municipal authority APIs for automated assignment.
